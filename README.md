# 家庭大字体电话本

给长辈使用的超大字号电话本：一张卡片一个联系人，点一下卡片手机就直接拨号。

## 现在能做什么

- 超大卡片：照片 / 小图案 + 称呼 + 名字 + 电话 + 备注
- 手机上点整张卡片，通过 `tel:` 直接拨号；电脑上点卡片不会拨号（电脑没有打电话的功能），
  而是直接把号码复制下来并弹提示，卡片上写的是「复制号码」而不是「拨号」
- 分类切换：家人 / 医生 / 物业 / 快递（分类可以自己加）
- 顶部「特大字号」按钮：一键把整页字再放大一档，选择会记住
- 可以添加到手机主屏幕，断网也能打开（PWA 离线缓存）
- **在网页上编辑联系人**：点右上角「编辑」，就能改称呼、名字、电话、分类、备注，
  还能上传头像照片（会自动压到 400 像素以内）。改完点「导出 data.js」替换项目里的同名文件即可

## 怎么改联系人和换照片

不用打开代码，直接在网页上改：

1. 页面上点「编辑」，再点某张卡片的「修改」；想加人就点「＋ 添加联系人」。
2. 照片点「选择照片」上传，会自动缩小，不会拖慢手机。
3. 点「保存」之后，改动**直接写进项目里的 `data.js`**，不用再手动导出替换；
   同时也会存在这台电脑的浏览器里，关掉网页再打开还在。
4. 想让长辈看到，把改动推送到 GitHub 就行：

```powershell
cd 'E:\网页试验\test2'
git add -A
git commit -m "更新联系人"
git push
```

推上去之后，长辈手机下次联网打开就是新的联系人。（照片已经内嵌在 `data.js` 里，
不需要另外放图片文件。）

> 每次写 `data.js` 之前，上一份会自动备份成 `data.js.bak`（不会提交到 GitHub）。
> 如果不小心改坏了，把它改名回 `data.js` 就能还原。
>
> 如果页面不是通过本地服务打开的（例如以后部署到网上），保存时写不了文件，
> 会提示「只存在浏览器里」——那就点「导出 data.js」，用它替换同名文件再推送。

> 「恢复默认」按钮会把数据还原成 `data.js` 里的原始内容，改动和照片都会没掉，慎点。
> 「导入」用来把导出的 `data.js` 读回来，换电脑时用得上。

## 怎么打开

方法一：双击 `启动网页.bat`，浏览器会自动打开 http://127.0.0.1:8000/ 。

方法二：在 VSCode 里打开终端，执行：

```bash
python serve.py 8000
```

然后浏览器访问 http://127.0.0.1:8000/ 。

方法三：直接双击 `index.html` 也能看页面，但这种方式下「添加到主屏幕」用不了。

窗口里会直接显示出两个网址：一个给这台电脑用（`127.0.0.1`），一个给手机用（`192.168.x.x`）。

## 怎么改成自己家的号码

打开 `data.js`，里面每一行就是一位联系人，照着现有格式改就行：

```js
{ group: "家人", relation: "大女儿", name: "王丽", phone: "13800000002", emoji: "👩", photo: "", note: "周末回家" },
```

| 字段 | 意思 |
| --- | --- |
| `group` | 分类，例如 家人 / 医生 / 物业 / 快递 |
| `relation` | 称呼，显示成卡片上最大的那行字 |
| `name` | 名字，不想要就写 `""` |
| `phone` | 电话，只写数字，页面会自动排成 138 0000 0002 |
| `emoji` | 没有照片时显示的小图案 |
| `photo` | 照片路径，例如 `images/wangli.jpg`；不用就写 `""` |
| `note` | 备注，例如「周末回家」；不用就写 `""` |

照片放在 `images` 文件夹里，路径写 `images/文件名.jpg` 即可；照片打不开时会自动退回小图案。

分类的顺序在文件末尾的 `DEFAULT_GROUP_ORDER` 里调整，新增的分类会自动排到后面。

> ⚠️ 现在 `data.js` 里的号码都是**示例号码**，请全部换成真实号码再给长辈用。
> 号码一定别写错，卡片点一下手机就直接拨出去了。

## 放到手机桌面上

1. 手机和电脑连同一个 Wi-Fi。
2. 电脑上运行 `启动网页.bat`，窗口里会显示「手机打开」的那个网址，照着输入即可。
3. 如果第一次弹出 Windows 防火墙提示，选「允许访问」，否则手机连不上。
4. 手机上用浏览器打开那个网址。安卓 Chrome：右上角「⋮」→「添加到主屏幕」；苹果 Safari：底部「分享」→「添加到主屏幕」。

以后断网也能打开，卡片照片和号码都缓存在手机里。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架 |
| `styles.css` | 样式，字号和配色在文件开头的 `:root` 里 |
| `data.js` | 联系人数据（改内容主要改这里） |
| `app.js` | 页面逻辑：分类切换、生成卡片、复制号码 |
| `manifest.webmanifest` | PWA 配置 |
| `service-worker.js` | 离线缓存：先联网取最新内容，没网时用缓存；改完代码刷新即可，不用清缓存 |
| `icons/` | 手机桌面图标 |
| `serve.py` | 本地预览服务器：把文件夹通过 http 递给浏览器。不是后端，不存数据 |
| `启动网页.bat` | 双击启动的入口，只负责调用 `serve.py` |

> `启动网页.bat` 故意只用英文字符，并且用 Windows 的 CRLF 换行。
> 原因是 cmd 解析 bat 文件里的中文时会出错（症状就是窗口一闪就消失）。
> 所以中文提示全部交给 `serve.py` 打印，改这个 bat 时请保持纯英文。

> `serve.py` 不往黑色窗口里写访问日志，而是写进 `访问记录.log`。
> 这不是洁癖：Windows 控制台一旦被鼠标选中，往窗口写日志的程序会被系统暂停，
> 整个服务就会卡死、手机和电脑都打不开。想知道手机有没有连上，看这个日志文件。
